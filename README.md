# ARBUZZ

Самостоятельный сайт AR-направления EVT для креативных команд и авторов идей. Можно прийти с замыслом или готовой 3D-моделью и заказать реализацию.

```sh
npm run dev
npm run check
npm run build
```

Локальный адрес: http://localhost:4180/. Production-сборка: `dist/`. Сайт работает с корня домена, без архива и маршрутов приложений EVT. Контакт: Telegram @awonk; форма готовит сообщение, но не отправляет его автоматически.

После hero — длинная композиция с одним путём зрителя: место → камера → взаимодействие с объектом. Мокапы `story-map.png`, `story-ar.png` и `story-brand.png` перенесены из исходного сайта ARBUZZ и подписаны как экраны прежнего проекта. Они иллюстрируют сценарий, а не наличие действующего приложения. Тексты и изображения доступны при обычной прокрутке, без вкладок и скрытых состояний.

Исходные рендеры и hero сохранены. Длинная секция оформлена в `story.css`, общая подача и блок о работе над проектом — в `narrative.css`. Форма готовит проверяемое сообщение в Telegram и сохраняет контекст идеи; посетитель отправляет его сам.
