# ARBUZZ

Самостоятельный сайт AR-направления EVT для креативных команд и авторов идей. Можно прийти с замыслом или готовой 3D-моделью и заказать реализацию.

```sh
npm run dev
npm run check
npm run build
```

Локальный адрес: http://localhost:4180/. Production-сборка: `dist/`. Сайт работает с корня домена, без архива и маршрутов приложений EVT. Контакт: Telegram @awonk; форма готовит сообщение, но не отправляет его автоматически.

Три примера — интерактивные эскизы, а не реальные AR tracking или клиентские кейсы. Исходная банка сохранена; жёсткая геометрическая обрезка удалена, прозрачная кромка мягко обрабатывается SVG-фильтром.

Страница ведёт от идеи к действию зрителя, затем объясняет вход в AR, процесс работы и форматы заказа. Визуальный слой `narrative.css` продолжает дизайн hero; переключение примеров меняет замысел, описание и действие зрителя. Путь работы — предлагаемая подача услуги, а не подтверждение проведённого пользовательского исследования.
